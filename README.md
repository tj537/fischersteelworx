# Fischer Steelworx

**Live:** https://tj537.github.io/fischersteelworx/

Eine kleine, private Link-Seite – quasi ein eigener Linktree – für Fischer Steelworx, die Hobby-Schweißkunst aus Hermaringen.

Oben stehen alle wichtigen Links (Ko-fi, Vinted-Shop, WhatsApp-Kanal, TikTok, Standort, Google-Bewertung), darunter ein kurzer Einblick in die Werkstatt: Schweißen, Laserbeschriftung, Metallkunst, Leder, Naturmaterialien und vieles mehr – alles handgemacht mit Liebe in Deutschland.

Es ist ein privates Familienprojekt, kein Unternehmen und kein offizieller Linktree.

## Aufbau

- `index.html` – die komplette Seite (HTML, CSS und JavaScript in einer Datei, kein Build nötig)
- `assets/` – Logo und Fotos der Werkstücke

## Ändern

Einfach `index.html` bearbeiten und auf `main` pushen. GitHub Pages aktualisiert die Seite danach automatisch (dauert meist 1–2 Minuten).
